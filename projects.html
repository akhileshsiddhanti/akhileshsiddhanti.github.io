Engineering projects

Selected production work at Salesforce, across test recommendation, failure analysis, model evaluation, and engineering tools.

Test Prioritizer for PRs

I owned the TF-IDF retrieval service that recommends tests for a pull request. The service scores a corpus of 3 million tests per request for two downstream services, handling approximately 10,000 requests per day with a p95 latency of about five seconds.

Model selection and production evaluation. I benchmarked TF-IDF against BERT, Word2Vec, and MiniLM. TF-IDF achieved 48.6% recall@2,500 compared with BERT’s 20%. In a production champion–challenger evaluation covering 5,000 PRs, recall@2,500 improved from 33.3% to 48.6%. I built hourly automated retraining, versioned model hot-swaps, and monitoring to operate the service.

Ranking and rollout. I added normalized coverage-ranking and XML-to-test mapping features to the XGBoost model, which reached 58% recall@2,500. I also replaced approximately 1,000 per-test prediction calls with one score-equivalent batch prediction, reducing ranking latency and unblocking production rollout within three weeks.

Compute and memory efficiency. I built AST-based test-minimization pipelines applicable to 7% of PRs, saving $100,000 in compute per month. Separately, I resolved out-of-memory failures in a 566,000-file similarity job by streaming chunked cosine similarity and pruning matrix columns from 1 billion to 1.2 million. This enabled the job to run within 4 GB while preserving numerical equivalence.

Stacktrace clustering and historical-fix retrieval

I proposed, owned, and built a stacktrace clustering service processing more than a billion stacktraces. Using over 150 normalization patterns, the service reduced the number of distinct stacktrace variants by approximately 98%.

I implemented real-time MiniLM embeddings and indexing in Vertex AI Vector Search. The service enables grouping and historical-fix retrieval for the Autonomous Test Fix Agent, failure grouping for Intelligent Test Reassignment, and better identification of flaky tests and infrastructure failures.

Autonomous Test Failure Fix Agent: evaluation and experimentation

I owned evaluation and experimentation for a production test-fix agent serving more than 6,000 engineers, collaborating with a data scientist and another software engineer on architecture and development.

I built validation datasets, prompt experiments, model benchmarks, and ICE/CodeBLEU scoring to compare LLMs and assess the quality of generated fixes.

Dashboard creation through Claude and Cursor

I built an LLM plugin for Claude and Cursor that generates live, database-backed Tableau dashboards from minimal prompts in under five minutes.

The plugin helps multiple internal teams create visualizations without needing prior Tableau experience.

Engineering dashboards and CI observability

I owned end-to-end development of company-wide engineering dashboards and backend services that track changes from work-item creation through customer deployment.

I built CI pipeline health and trend monitoring with automated Slack alerts for deviations, alongside test-information and predictive-performance dashboards and a Test Debug View for searching and analyzing test failures.
